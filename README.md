# Glyphly Fonts

> A modern, open-source icon library for developers and designers.

**Glyphly Fonts** is a growing collection of clean, scalable, developer-friendly icons designed for use across websites, applications, dashboards, documentation, and creative projects.

🚧 **Status: Under Development**

---

## ✨ Features

* 🎨 Clean and consistent icon designs
* ⚡ Lightweight and developer-friendly
* 📐 Scalable vector icons
* 🌐 Designed for web projects
* 🧩 Easy-to-use icon naming system
* 🔧 Multiple categories
* 📦 Simple integration
* 🛠️ Continuously expanding library
* 💻 Open-source and GitHub-friendly

## 🧩 Design Philosophy

Glyphly Fonts focuses on:

**Consistency**
Icons should feel like they belong to the same visual system.

**Simplicity**
Icons should remain recognizable even at small sizes.

**Scalability**
Vector-based icons should work across different screen sizes.

**Developer Experience**
Finding and integrating an icon should be simple.

**Extensibility**
The library is designed to grow with new categories, styles, and integrations.
